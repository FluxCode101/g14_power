## Description: 

Helper Scripts to reduce Power-Consumption for the
- Asus Zephyrus G14 Laptop.
- Using custom g14 Arch Kernal

## Installing (kde):
Clone the Repo
`git clone https://github.com/FluxCode101/g14_power`

Go to KDE Settings/power management/
Add the individual scripts to ac and battery behaviours.
